## Requisitos minimos

Si de acaso tienes una patata de 1MB, no puedes probarlo, pero si tienes una PC y no estas seguro si correra, aqui te lo paso 

| Navegador | JavaScript | Soporte | CPU | RAM | Graficos | Almacenamiento | Resolucion |
| :--- | :---: | :--: | :--: | :--: | :--: | :--: | --: |
| Chrome, Edge, Firefox, Safari y cualquier navegador moderno | JavaScript activado | Canvas 2D, localStorage, AudioContext, MutationObserver y CSS Grid / Flexbox | cualquier procesador de doble núcleo o superior, aunque funciona en uno muy básico | 1 a 2GB | cualquier GPU integrada | unos pocos MB para el HTML y la caché del navegador | 800×600 |
